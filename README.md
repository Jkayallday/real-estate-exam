# Michigan Real Estate Exam — Holloway's Real Estate Institute Audio & Transcripts

Complete study repository containing all **57 audio tracks** (`Track01.mp3`–`Track57.mp3`), **9 companion PowerPoint slide decks** (`Lesson 1`–`Lesson 9`), and **100% verbatim transcripts** in Markdown, Microsoft Word (`.docx`), and an interactive searchable Web Study Portal (`index.html`).

## Included Files

- **[`Holloways_Real_Estate_Audio_Transcripts.md`](./Holloways_Real_Estate_Audio_Transcripts.md)** — Complete, verbatim Markdown transcript of all 57 tracks across Lessons 1–9, including a master Track Index table and cross-track notes.
- **[`Holloways_Real_Estate_Audio_Transcripts.docx`](./Holloways_Real_Estate_Audio_Transcripts.docx)** — Microsoft Word document containing the complete transcripts organized by Lesson and Track.
- **[`Holloways_Real_Estate_Audio_Transcripts.html`](./Holloways_Real_Estate_Audio_Transcripts.html) / [`index.html`](./index.html)** — Interactive searchable HTML study portal with embedded audio players (supporting both local and remote MP3 playback), lesson filtering, slide downloads, and print/PDF export.
- **`audio/Track01.mp3` – `audio/Track57.mp3`** — All 57 audio tracks from Holloway's Real Estate Institute (`https://hollowaysinstitute.biz/audio/`).
- **`slides/Lesson-1-Student-v2.ppt` – `slides/lesson-9-Student-v2.pptx`** — All 9 student PowerPoint presentations for Lessons 1–9.
- **[`build_docs.py`](./build_docs.py)** — Python build & verification script that parses `Holloways_Real_Estate_Audio_Transcripts.md`, verifies all 9 lessons and 57 tracks, and generates the `.docx` and `.html` outputs.
